# 技術ドキュメントを Web 画面の管理者専用にする

日付: 2026-11-26　規模: 小さな変更

## 目的と理由

Web 画面（`rag_web/`）で、技術ドキュメント（`docs_store.sqlite3`）に関する操作を
管理者以外から隠す。利用者のコーディングは VS Code で行うため、Web 画面の利用者に
技術ドキュメントを見せる必要がない。

## ゴール

- 管理者以外には、技術ドキュメントに関するものを画面に出さない。
  - チャットの検索対象「技術ドキュメント」のラジオボタン
  - 取り込みコマンドの案内（`docs_ingest_command`）
  - Cowork の「技術ドキュメントを参照」チェック
  - Cowork の案内文に出てくる「技術ドキュメント」の文字
- サーバー側でも断る。画面で隠すだけにせず、API を直接呼んでも使えないようにする
  （PR #12 で取り込み元フォルダ名を隠したときと同じ考え方）。
- 管理者は、ログインすれば今までどおり検索・参照でき、コマンドの案内も見られる。

## ゴールにしないこと

- CLI（`scripts.fetch_docs` / `scripts.ingest_source`）の制限。シェルに入れる人は
  もともと管理者である。
- MCP サーバ（`search_documents`）の変更。もともと `docs_store` を読まない。
- Cowork のソースコード出力形式（`.py` / `.go` など）の制限。利用者にも残す。
  ただし利用者が作るときは、技術ドキュメントを引かずに生成する。

## 採った方式と、採らなかった方式

- **採った: 今ある API と画面に、管理者かどうかの確認を足す。** 判定には既存の
  `is_admin`（セッション Cookie）を使う。画面はログイン状態（`state.admin`）に合わせて
  表示を切り替える。
- 採らなかった: 管理者専用の API を別に作る（`/api/admin/docs/...`）。チャットの
  処理が二重になり、片方だけ直す事故が起きやすい。
- 採らなかった: 設定で技術ドキュメントを丸ごと無効にする。管理者も使えなくなる。

## 振る舞い

### サーバー（`rag_web/app.py`）

- `GET /api/status?corpus=docs`、`POST /api/chat`（`corpus: "docs"`）、
  `POST /api/cowork`（`use_docs: true`）は、管理者でなければ 401
  「管理者としてログインしてください」で断る（`require_admin` と同じ文言・状態コード）。
  `/api/chat` はストリームを始める前に断る。
- `docs_ingest_command` は `corpus=docs` の応答にだけ入れる。社内資料の応答からは外す。
  利用者に返る経路がなくなる。

### 画面（`rag_web/static/`）

- 技術ドキュメントに関する要素には共通の印（クラス）を付け、HTML では最初から隠しておく。
  `applyAdmin()` が管理者のときだけ表示する。初めに利用者へ一瞬見えてしまうのを防ぐため。
- 管理者でなくなったとき（ログアウト・セッション切れで `loadMe` が false を返したとき）:
  - 検索対象が「技術ドキュメント」なら「社内資料」に戻す。会話履歴があれば消し、
    「ログアウトしたため、検索対象を社内資料に戻しました。」のように画面に出す
    （検索対象を切り替えたときと同じ理由で、履歴を残すと検索が壊れる）。
  - Cowork の「技術ドキュメントを参照」チェックを外す。ソースコード形式を選んだときの
    自動チェックも、管理者のときだけ行う。
- 管理者の操作が 401 で返ったときに `loadMe()` を呼ぶ既存の流れに、チャットと Cowork の
  技術ドキュメント利用も乗せる。期限切れのあと最初の操作でエラーが出て、表示が
  利用者向けに戻る。

## 作る側の判断に任せたこと（こちらで決めた点）

- 生成中にログアウトした場合: ログアウトボタンを生成中は押せなくする。生成中に
  会話履歴を消したり検索対象を変えたりすると表示が壊れるため。すでに始まった生成は、
  開始時に確認済みなので最後まで走らせる。
- ブラウザの「戻る」や再読み込みで、ラジオボタンの「技術ドキュメント」が選ばれた状態に
  復元されても、`loadMe` の結果が利用者なら上の手順で社内資料に戻す。
- テストは `tests/test_web_app.py` に、利用者が断られること・管理者が通ることを
  3つの API それぞれで足す。README の Cowork の節と画面の説明も、管理者専用である旨に直す。
