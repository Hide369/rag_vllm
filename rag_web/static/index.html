Cowork でできること・使い方

Cowork でできること：社内資料や技術ドキュメントを検索し、その内容を根拠に文書やソースコードのファイルを作って、ダウンロードできます。

  • 登録したフォーマットファイル（Word・Excel などの雛形）の空欄を埋めて、同じ形式のファイルを作る
  • フォーマットファイルを使わずに、報告書・手順書・一覧表・スライド・ソースコードなどを、選んだ出力形式で作る
  • 手元の資料を添付したり、テキストを貼り付けたりして、それを材料に作る（この回だけ使い、DBには入れません）

使い方

  1. フォーマットファイルを選びます。雛形を使わないときは「」を選び、出力形式を選びます。雛形は「フォーマットファイルを登録・削除」から登録できます。
  2. 参照する資料（社内資料・技術ドキュメント）にチェックを入れます。必要なら資料を添付するか、テキストを貼り付けます。
  3. 下の入力欄に、作りたいものと盛り込む内容を書いて「送信」を押します。できあがると「ダウンロード」ボタンが出ます。

フォーマットファイルの書き方（埋め込み文字列）

  • 埋めてほしい箇所に {{欄の名前}} と書きます。例：{{会議名}}、{{決定事項}}。名前は日本語で構いません。
  • 使える形式は です。本文のほか、表の中にも書けます。
  • AI は欄の名前を見て、何を書くかを決めます。中身が分かる名前にしてください（「項目1」より「決定事項」）。
  • 同じ名前を複数の場所に書くと、どこにも同じ内容が入ります。
  • 資料から根拠が見つからなかった欄は、{{名前}} のまま残ります。できあがったファイルで手で書き足してください。
  • 図で表すほうがよい欄には、図が画像で入ることがあります。図にできなかったときは、図の元になる文字（Mermaid の記法）がそのまま入ります。
  • {{ }} の中に { や } は書けません。

依頼はチャットの会話履歴には残りません。生成には時間がかかることがあります。
